# pandora

**Knowledge belongs in data, not in weights.**

pandora splits a big language model into three parts: a 🧠 **decider** that reasons, 📚 **data** that lives outside the model, and a ✍️ **drafter** that writes answers only from that data. When a fact changes, you change the data. No retraining.

- 🌐 Concept page: [`index.html`](index.html) (live at https://s-somnium.github.io/pandora/)
- 🤗 Models, app and training code: https://huggingface.co/S-Somnium/pandora
