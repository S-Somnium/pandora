Knowledge belongs in data,
not in weights.

pandora splits a big language model into three parts: a decider that reasons, data that lives outside the model, and a drafter that writes answers only from that data. When a fact changes, you change the data. No retraining.

The problem with knowledge in the weights

Today's LLMs

Knowledge is memorised during training

  • Goes stale. When a price, a policy or a fact changes, the model keeps the old one until someone trains it again.
  • Heavy. The whole model, with everything it memorised, has to be loaded in RAM to answer anything.
  • Can invent. Free-text generation from memory can produce fluent answers that aren't true.
  • Hard to trace. You can't point to where an answer came from.
pandora

Knowledge is read when you ask

  • Always current. Update a file or a record and the next answer uses it.
  • Light. The models only learn how to read and decide: 157 M + 117 M parameters, milliseconds on a laptop.
  • Grounded. Every draft is copied from the data, so facts can't be made up.
  • Traceable. Each answer points back to the text it came from.

Three parts instead of one

🧠

Decider

Logic and reasoning. Reads the question, the data and the candidate answers, and picks one, or says none. It holds skills, not facts.

📚

Data

The knowledge: documents, records, policies, logs, agent transcripts. It lives outside the model, in files, a database or a search index, and you change it any time.

✍️

Drafter

Drafts candidate answers only from the data it is given: copied spans, a small fixed vocabulary (yes/no, numbers) or schema-checked tool calls.

How an answer is made

1
The question and the relevant data go to the drafter. Long files are cut down to their most relevant blocks first.
2
The drafter proposes a handful of candidate answers. Each one is a piece of the data, never free text from memory.
3
The decider reads the question, the same data and the drafts in one pass (about 24 ms), and picks the best one. If none fits, it answers none instead of guessing.

Why it matters

🔄 Always up to date

Prices, policies, inventories and tickets change daily. Point pandora at the current data and it answers from the current data.

🔐 Private by design

Your documents are read at answer time and never trained into weights that could leak them or need deleting later.

⚡ Runs anywhere

Without a memorised world inside, the models are small: 158 MB for the decider, decisions in milliseconds on a laptop, fully offline.
